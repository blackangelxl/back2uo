# Back2Uo Mod v.2.1 Rebuild Index - English

## MOD

### New

- zk_libcod support implemented (`z_svr_back2uo_2.1_libcod.iwd`, `zk_libcod.cfg`), with fallback functions for servers without zk_libcod.
- Admin Console Commands implemented (artillery, airplanes, mortar, anti-aircraft, thunder, rain, snow).
- Debug & Logging System implemented (event log and function trace).
- Map Dawnville Classic (`mp_dawnville_cl`) added and included in the map rotation.
- Example Server Config, Map Rotation, Default & Dev Mod Configs added.

### Bugfixes

- Favourite Menu revised.
- Connecting bug revised.
- Gametype Clock position revised.
- Mod Logo Slogan revised.
- Random Map Rotation revised.
- Menu UI Elements revised.

## HUD Elements

### Bugfixes

- Sprint Hud revised.
- Binocular Hud revised.
- Ranking Hud position revised.
- Team Score revised.
- Health bar position revised.

## Effects

### New

- Airplanes, Mortar, Artillery & Anti-Aircraft count configurable (`*_max_count`).
- Airplanes hit by Flak can crash.
- Airplanes fly on medium sized maps.
- Bullet Drop with zk_libcod implemented.

### Bugfixes

- Airplane, Flak & Airplane Sounds revised.
- Airplane multiple crash sounds revised.
- Mortar & Artillery Earthquake revised.
- Panzerschreck explosion revised.

## Systems

### New

- Test Bots AI implemented (waypoints, path finding, climbing, jumping, melee, skill 1 -> 3, team names).
- Native Sprint (player speed) with zk_libcod implemented, weapon swap as fallback.
- Artillery Strike is used up after a switch to spectator.

### Bugfixes

- Ranking System revised.
- AFK Detection & AFK Artillery revised.
- Sprint while moving revised.
- Helmet Popping revised.
- Killed Player bug revised.
- Bots reconnect after map rotation revised.
